# Project Rules

## No AI Attribution
- NEVER add comments, metadata, or text that references AI tools (Claude, Anthropic, Vercel v0, ChatGPT, Copilot, etc.)
- NEVER add "Co-Authored-By" lines mentioning AI in git commits
- NEVER add "Generated by", "Built with", or similar AI attribution anywhere in code or documentation
- Keep all code and documentation looking entirely human-authored
